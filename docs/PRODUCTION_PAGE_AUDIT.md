# Production Page & UX State Audit: UPI-Shield

This document provides a factual, evidence-based audit of all production-grade pages, customer lifecycle flows, legal notices, and UX states for **UPI-Shield** (Contextual Digital Payment Scam & Coercion Detector).

---

## 1. System Context & Evidence

- **Application Type**: Contextual Digital Payment Scam & Coercion Detector (single-page React/TypeScript application with Express API backend).
- **Core Technology**: React 19, TypeScript, Tailwind CSS v4, Express 4.21, Node.js runtime, `@google/genai` (Gemini 3.8 Flash / 3.1 Flash Lite) with a zero-dependency server-side local heuristic fallback engine.
- **Data Model & Storage**: Ephemeral in-memory analysis; zero persistent database models; no user accounts or persistent session tokens.
- **Monetization & Transactions**: Free utility application. No e-commerce cart, checkout, physical shipping, billing, or subscription payments exist. The app evaluates payment message threats and UPI deep links, but does not initiate or execute financial transactions.
